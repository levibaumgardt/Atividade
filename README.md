# Projeto: Filtragem de Notas de Alunos com Python

Este repositório contém um script desenvolvido para automatizar e filtrar o desempenho escolar de estudantes, separando-os de acordo com suas médias em listas de aprovação e recuperação.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Conceitos Praticados:** Estruturas de dados (Dicionários e Listas), Estruturas Condicionais (`if`/`else`), Laços de Repetição (`for`) e Funções.

## 📋 Como Executar o Script
1. Certifique-se de ter o Python instalado em seu computador.
2. Baixe ou clone este repositório.
3. No terminal ou prompt de comando, execute o arquivo:
   ```bash
   python script.py
   ```

## ⚙️ Funcionamento do Código
O programa processa um dicionário contendo o nome dos alunos e suas respectivas notas. Ele calcula a média final e exibe:
* Alunos com nota **igual ou superior a 7.0** (Aprovados).
* Alunos com nota **inferior a 7.0** (Recuperação).
# Atividade Prática: Gerador de Senhas Seguras em Python

Este projeto consiste em um script automatizado em Python que gera senhas aleatórias e seguras com base no comprimento definido pelo usuário. A aplicação utiliza boas práticas de programação, tratamento de exceções e a biblioteca nativa `random`.

## 🚀 Funcionalidades

- **Personalização de tamanho:** Permite que o usuário defina o comprimento exato da senha.
- **Segurança robusta:** Combina letras minúsculas, maiúsculas, números e caracteres especiais.
- **Tratamento de Erros:** Evita que o programa quebre caso o usuário digite um texto no lugar de um número.

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- Biblioteca `random` (nativa do Python para geração de dados pseudoaleatórios)
- Biblioteca `string` (nativa do Python para manipulação de constantes de caracteres)

## 📋 Como Executar o Projeto

Certifique-se de ter o Python instalado em sua máquina. Você pode verificar rodando `python --version` no seu terminal.

1. Baixe o arquivo `script.py` ou clone este repositório.
2. Abra o terminal (ou prompt de comando) na pasta onde o arquivo está salvo.
3. Execute o comando abaixo:

```bash
python script.py
```

4. Digite o número de caracteres desejado e pressione **Enter** para ver sua nova senha na tela.
